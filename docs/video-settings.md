# video_settings.json 配置说明

本文件用于配置 PPT 视频生成流水线的视频参数与字幕参数。位于 `config/video_settings.json`。

> JSON 标准不允许注释，因此本文件本身不包含任何注释。所有配置项的含义请查阅本文档。

---

## 视频基础参数

### aspect_ratio

- **作用**：视频画幅比例。控制生成视频的宽高比，会自动映射到对应的预设分辨率。
- **可选值**：
  | 值 | 分辨率 | 适用场景 |
  |----|--------|---------|
  | `"16:9"` | 1920×1080 | 横屏，YouTube、桌面视频、传统电视 |
  | `"9:16"` | 1080×1920 | 竖屏，手机、抖音、TikTok |
  | `"4:3"` | 1440×1080 | 传统视频、PPT、教育课件 |
  | `"1:1"` | 1080×1080 | 正方形，社交媒体 |
  | `"21:9"` | 2560×1080 | 超宽屏，电影、沉浸式体验 |
- **说明**：比例与分辨率的映射关系定义在 `config/video_aspect_ratios.json` 中。

### resolution

- **作用**：视频输出分辨率（宽×高，像素）。
- **可选值**：
  - 预设值：如 `"1920x1080"`、`"1080x1920"`、`"1440x1080"`、`"1080x1080"`、`"2560x1080"`
  - 自定义值：任意 `"宽x高"` 格式字符串，如 `"1280x720"`
- **说明**：当值为预设比例对应的分辨率时，会被 `aspect_ratio` 自动覆盖；如果是自定义分辨率，则保持不变。

### fps

- **作用**：视频帧率（每秒帧数）。
- **可选值**：正整数
  | 值 | 说明 |
  |----|------|
  | `24` | 电影质感 |
  | `30` | 标准视频（默认推荐） |
  | `60` | 高流畅度 |
- **说明**：值越大画面越流畅，但文件体积也越大。

## 视频动效参数

### video_effect

- **作用**：单张幻灯片图片在视频片段中的运动效果。
- **可选值**：
  | 值 | 说明 |
  |----|------|
  | `"none"` | 无特效，图片静止显示 |
  | `"static"` | 静态展示（与 none 类似，走静态缩放分支） |
  | `"ken_burns"` | 肯·伯恩斯效果，缓慢平移+缩放，营造电影感 |
  | `"zoom_in"` | 缓慢放大效果 |

### fade_in_ms

- **作用**：视频片段开头淡入时长（毫秒）。
- **可选值**：非负整数
  | 值 | 说明 |
  |----|------|
  | `0` | 无淡入（默认） |
  | `500` | 淡入 0.5 秒 |
  | `1000` | 淡入 1 秒 |

### fade_out_ms

- **作用**：视频片段结尾淡出时长（毫秒）。
- **可选值**：非负整数，用法同 `fade_in_ms`。

### transition

- **作用**：多个视频片段拼接时的转场效果。
- **可选值**：
  | 值 | 说明 |
  |----|------|
  | `"none"` | 无转场，直接拼接 |
  | `"fade"` | 淡入淡出转场 |
  | `"dissolve"` | 溶解转场 |

### transition_duration

- **作用**：转场效果持续时间（秒）。
- **可选值**：正浮点数
  | 值 | 说明 |
  |----|------|
  | `0.5` | 0.5 秒（默认推荐） |
  | `1.0` | 1 秒 |
- **说明**：仅在 `transition` 不为 `"none"` 时生效。

### device_scale_factor

- **作用**：HTML 截图的设备缩放因子（Playwright `device_scale_factor`）。
- **可选值**：正浮点数
  | 值 | 说明 |
  |----|------|
  | `1.0` | 标准分辨率截图 |
  | `2.0` | 2 倍清晰度截图（默认推荐，画面更细腻） |
  | `3.0` | 3 倍清晰度截图，文件更大 |
- **说明**：值越大截图越清晰，但内存占用和耗时也越高。

## 字幕参数

### enable_subtitles

- **作用**：是否启用字幕功能。
- **可选值**：
  | 值 | 说明 |
  |----|------|
  | `true` | 启用字幕，生成 SRT 文件并烧录到视频画面 |
  | `false` | 关闭字幕，不生成 SRT，行为与无字幕版本完全一致 |
- **说明**：关闭时无额外性能开销。

### subtitle_mode

- **作用**：字幕显示粒度，决定按句还是按字显示。
- **可选值**：
  | 值 | 说明 |
  |----|------|
  | `"sentence"` | 逐句模式，一整句字幕同时显示（默认推荐，阅读体验好） |
  | `"word"` | 逐字模式，按词/字逐个显示（类似歌词效果） |

### subtitle_font

- **作用**：字幕字体名称。平台按此名称在系统里只读解析对应的字体文件，用该文件渲染字幕。
- **可选值**：
  | 值 | 说明 |
  |----|------|
  | `""` | 空字符串，不渲染字幕（前端"启用字幕"复选框置灰） |
  | `"Microsoft YaHei"` | 微软雅黑 |
  | `"SimHei"` | 黑体 |
  | `"SimSun"` | 宋体 |
  | `"KaiTi"` | 楷体 |
  | `"FangSong"` | 仿宋 |
- **说明**：留空时无字幕（不再自动检测）。指定字体名时，若系统找不到该字体，视频生成失败并提示"未找到字体文件"；若解析到的是 `.ttc` 多 face 集合文件，则使用其第一个 face 渲染，并提示建议改用单 face 字体（`.ttf`/`.otf`）。当 `subtitle_font_file` 同时配置时，**以 `subtitle_font_file` 为准**。

### subtitle_font_file

- **作用**：直接指定字幕字体文件的路径（可选）。配置后**优先于** `subtitle_font` 使用，直接加载该文件渲染字幕，不经过字体名解析。
- **可选值**：
  | 值 | 说明 |
  |----|------|
  | `""` | 空字符串，不使用该配置项，走 `subtitle_font` 字体名解析（默认） |
  | `"C:/Users/xx/SourceHanSansSC-Regular.otf"` | 字体文件绝对路径 |
  | `"/usr/share/fonts/opentype/noto/NotoSansCJKsc-Regular.otf"` | Linux 下的字体文件路径 |
- **说明**：
  - **仅支持单 face 字体文件（`.ttf`/`.otf`）**；配置为 `.ttc`/`.otc` 多 face 集合文件时，视频生成失败并提示"仅支持单 face 字体文件"。
  - 文件不存在时，视频生成失败并提示"字幕字体文件不存在"。
  - 优先级：`subtitle_font_file` > `subtitle_font`。两者均未配置时，无字幕（复选框置灰）。

### subtitle_font_size

- **作用**：字幕字号，单位为像素。
- **可选值**：正整数
  | 值 | 说明 |
  |----|------|
  | `16` | 较小 |
  | `18` | 偏小 |
  | `24` | 中等 |
  | `32` | 较大 |
  | `36` | 居中（当前默认） |
  | `48` | 大号 |
- **说明**：1920×1080 视频推荐 32~48；9:16 竖屏视频因宽度较窄，建议更小一些。

### subtitle_color

- **作用**：字幕文字颜色。
- **可选值**：
  | 值 | 说明 |
  |----|------|
  | `"white"` | 白色（默认推荐） |
  | `"black"` | 黑色 |
  | `"red"` | 红色 |
  | `"green"` | 绿色 |
  | `"blue"` | 蓝色 |
  | `"yellow"` | 黄色 |
  | `"cyan"` | 青色 |
  | `"magenta"` | 品红色 |
- **说明**：也支持十六进制色（如 `0x00FF00`）。
- **前端 UI**：视频设置页字幕区域提供**取色器 + 实时预览**（预览文字以浅色底模拟 PPT 背景，实时显示所选颜色）。用户在表单选的字体颜色会在生成时**保存到项目配置** `video_config.json`（与语音人设、启用字幕一起，由 `_save_user_video_settings` 写入），刷新/换会话后仍保留。

### subtitle_outline_color

- **作用**：字幕描边颜色，用于提升字幕在复杂背景上的可读性。
- **可选值**：同 `subtitle_color`。
- **默认值**：`"black"`（黑色描边，配白字最常用）。

### subtitle_outline_width

- **作用**：字幕描边宽度（像素）。
- **可选值**：非负整数
  | 值 | 说明 |
  |----|------|
  | `0` | 无描边 |
  | `1` | 细描边 |
  | `2` | 中等描边（默认推荐） |
  | `3` | 粗描边 |

### subtitle_position

- **作用**：字幕在画面中的垂直位置。
- **可选值**：
  | 值 | 说明 |
  |----|------|
  | `"top"` | 顶部居中 |
  | `"middle"` | 中部居中 |
  | `"bottom"` | 底部居中（默认推荐） |

### subtitle_margin

- **作用**：字幕距离画面边缘的垂直边距（像素）。
- **可选值**：非负整数
  | 值 | 说明 |
  |----|------|
  | `0` | 紧贴边缘 |
  | `15` | 靠近边缘（当前默认） |
  | `40` | 中等边距 |
  | `80` | 远离边缘 |
- **说明**：位置为 `bottom` 时表示距画面底部的距离；为 `top` 时表示距顶部的距离；为 `middle` 时不生效。

## 配置示例

```json
{
  "aspect_ratio": "16:9",
  "resolution": "1920x1080",
  "fps": 30,
  "video_effect": "none",
  "fade_in_ms": 0,
  "fade_out_ms": 0,
  "transition": "none",
  "transition_duration": 0.5,
  "device_scale_factor": 2.0,
  "enable_subtitles": true,
  "subtitle_mode": "sentence",
  "subtitle_font": "",
  "subtitle_font_size": 36,
  "subtitle_color": "white",
  "subtitle_outline_color": "black",
  "subtitle_outline_width": 2,
  "subtitle_position": "bottom",
  "subtitle_margin": 15
}
```

## 字幕样式调整速查

| 需求 | 调整项 | 方向 |
|------|--------|------|
| 字幕太小 | `subtitle_font_size` | 增大 |
| 字幕太大 | `subtitle_font_size` | 减小 |
| 字幕太靠上 | `subtitle_margin` | 减小 |
| 字幕太靠下 | `subtitle_margin` | 增大 |
| 换字体 | `subtitle_font` | 填具体字体名 |
| 换颜色 | `subtitle_color` / `subtitle_outline_color` | 填颜色名 |
| 关闭字幕 | `enable_subtitles` | 设为 `false` |
