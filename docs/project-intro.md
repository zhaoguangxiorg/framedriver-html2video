# 驭帧(FrameDriver)·驭帧让每一帧知识，都尽在掌控。

> 输入一个主题，自动产出带语音讲解、字幕的 PPT 讲解视频。
> 从想法到成片，全流程 AI 自动化，无需手动做 PPT、写讲稿、录音和剪辑。

---

## 1. 项目定位：它解决什么问题？

做一条"PPT 讲解视频"通常需要四步：**做 PPT → 写讲稿 → 录音 → 剪辑合成**，每一步都耗时费力。

**驭帧** 把这个过程交给 AI 全流程自动化：

| 传统做法 | 驭帧的做法 |
|----------|-----------|
| 手动排版 PPT | AI 根据主题自动生成内容与幻灯片设计 |
| 逐页写讲稿 | AI 生成每张幻灯片的逐字讲解稿 |
| 人工录音 | edge-tts 语音合成，支持多音色、语速调节 |
| 剪辑软件拼视频 | FFmpeg 自动合成、字幕 |

你只需要：**输入主题 → 检查修改 → 一键生成**。

## 2. 核心功能

### ✍️ 智能内容创作
- 输入主题，AI 自动生成结构化的 PPT 大纲：标题、正文要点、逐字讲解稿
- 支持多轮对话修改，不满意随时调整

### 🎨 智能幻灯片设计（多智能体协作）
- 主智能体（Orchestrator）负责调度，Worker 逐张设计幻灯片 HTML
- 内置「幻灯片设计师」「幻灯片结构管理员」两个专业子智能体
- 支持新增、删除、移动幻灯片，逐张修改内容与逐字稿
- **人工介入机制**：需要你决策时，以问题卡片的形式提问（单选/多选/问答/确认），作答后继续执行

### 🎬 一键视频生成
- 幻灯片 HTML → 高清图片 → 逐字稿语音 → 视频合成，全自动流水线
- 支持视频比例（16:9 / 9:16 / 4:3 / 1:1 等）、分辨率、帧率配置
- 多音色语音、语速/音量/音调调节、语音人设
- **字幕渲染**：自动生成字幕，可配置字体、颜色、位置

### 🛠 工程化能力
- 主从智能体架构：主子分工明确，有效防止状态爆炸，语义漂移，人工介入机制防止智能体瞎猜。
- 会话管理：多项目并行，历史消息可恢复
- 模型管理：可视化配置多套大模型（OpenAI 兼容协议），聊天中随时切换
- 幻灯片画廊：整套 PPT 预览、下载
- 高级生成：逐张生成视频、手动合成，精细控制

## 3. 三步上手

```
第一步：内容创作（选项卡 ①）
  新建会话 → 输入主题 → 多轮修改 → 满意

第二步：HTML 设计（选项卡 ②）
  发送消息让 AI 生成幻灯片 → 预览 / 逐张修改 / 增删移动 → 满意

第三步：生成视频（选项卡 ③）
  配置比例 / 语音人设 / 字幕 → 一键生成 → 下载视频
```

> 全程在浏览器完成，无需安装客户端，无需手动复制粘贴。

## 4. 整体架构

### 4.1 分层架构（单向依赖）

```
表现层 presentation        api（薄路由）+ 原生前端
     ↓
应用服务层 appservice       全部业务逻辑
     ↓
领域层 domain + 智能体层 agent + 流水线 video_pipeline
     ↓
共享层 shared              配置 / 加密 / 文件工具
```

- **表现层**：只做 HTTP 参数透传，不写业务逻辑
- **应用服务层**：集中管理全部业务（智能体运行、SSE 流、视频任务、会话、模型）
- **领域层**：数据库表、数据存取、业务规则
- **智能体层**：AI 智能体（内容创作 + HTML 设计主从架构）+ 模型网关
- **流水线**：确定性视频生成，无 LLM 参与

### 4.2 多智能体协作（整体架构）

```
用户题目
   │
   ▼
┌──────────────────────────────────────────────────────────┐
│  ContentAgent（内容创作智能体）                            │
│  · 2 个工具：read_content / save_content                  │
│  · 生成 Markdown 内容 → save_content 写入 content.md       │
│  · 支持多轮修改                                           │
└──────────────────────┬───────────────────────────────────┘
                       │ content.md（前端自动串联，非手动复制）
                       ▼
┌──────────────────────────────────────────────────────────┐
│  HTMLAgent（PPT 设计，Orchestrator-Worker 主从架构）       │
│  · OrchestratorAgent（主智能体，6 工具）                    │
│      init_project / read_content_md / read_style_spec      │
│      / update_style_spec / update_video_config / ask_user  │
│  · WorkerAgent「slide-designer」（5 工具，每次一张）         │
│      read_full_content / read_style_spec / read_slide_html  │
│      / save_slide_content / save_slide_html                │
│  · SlideManagerAgent「slide-manager」（4 工具）             │
│      read_slides_meta / insert_slide / delete_slide         │
│      / move_slide                                          │
└──────────────────────┬───────────────────────────────────┘
                       │ project_id
                       ▼
┌──────────────────────────────────────────────────────────┐
│  视频生成大工具（generate_video）                           │
│  · 确定性流水线，无 LLM                                    │
│  · 内部步骤：HTML→图片 / 逐字稿→音频 / 图+音→单段 / 拼接      │
│  · 可选字幕渲染                                            │
│  输出：最终视频 MP4                                        │
└──────────────────────────────────────────────────────────┘
```

### 4.3 数据流转

各阶段通过**项目目录**（文件系统）交换数据，`project_id` 串联全程：

```
content.md → slides_data.json + 每张 slide_XX/（HTML/内容/逐字稿）
→ 视频流水线产物（图片/音频/单段）→ final_video.mp4
```

## 5. 技术栈

| 层次 | 技术 |
|------|------|
| 后端框架 | Python + FastAPI（REST + SSE 流式） |
| 智能体框架 | deepagents（基于 LangGraph，主从子智能体 + SQLite checkpointer 记忆） |
| 大模型接入 | 多模型网关（OpenAI 兼容协议，可视化配置，请求级切换） |
| 数据库 | SQLite（会话/消息/模型配置 + 智能体状态） |
| HTML 转图 | Playwright + Chromium 无头浏览器 |
| 语音合成 | edge-tts（微软在线 TTS） |
| 视频处理 | FFmpeg + imageio-ffmpeg（转场/动效/字幕 drawtext） |
| 前端 | 原生 HTML/CSS/JS（零第三方依赖，免费商用字体） |
| 数据模型 | Pydantic v2 |
| 密钥安全 | Fernet 加密（API Key 落库加密） |

## 6. 项目亮点
- **遵循人的习惯**：人做 PPT 时，会先在心中想好复述、把要讲的内容复述一遍，理清表达逻辑后再动手。先有逐字稿，再设计幻灯片， AI依据内容与讲稿设计幻灯片——让每一页都服务于"要讲什么"，而非为设计而设计。
- **全流程可控可追溯**：生成各个环节都可人工介入，做到精准可控，可讲解语音每一个字都是按照预期输出，可断点，可修正，中间产物目录留痕。
- **可控与高效兼得**：既可以各个环节介入精准调整，也可默认一步一步一键快速生成。
- **低成本与成本可控**：记忆模型网关可以切换低成本模型，生成一份ppt讲解视频成本可控，成本极低，几乎为零。

- **主从智能体架构**： 主子分工明确，主智能体负责协调调度与记忆，子智能不记忆无状态。这样避免上下文爆炸和漂移
- **人工介入机制**：AI 遇到需要你拍板的节点，用问题卡片暂停等你作答，不瞎猜
- **既灵活与开箱即用兼得**：三层配置，参数 > 项目配置 > 全局默认，灵活且开箱即用
- **确定性视频流水线**：视频生成全程无 LLM，结果稳定可控、成本低
- **前后端可分可和**：前端零依赖，无 CDN、无框架，部署即用，前后端分离，可分可和。
